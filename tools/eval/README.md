# MindCode Eval Harness

A repeatable evaluation harness to score the quality of mind map plans and generated builds across varied prompts.

## Files

- `prompts.json`: 8 varied app ideas (chat app, banking app, recipe box, portfolio, habit tracker, marketplace, booking, agency PM tool).
- `run.mjs`: CLI runner that executes evaluation sessions against the local API and generates `report.md`.
- `score.mjs`: Pure scoring functions for plans and build HTML, and Markdown table formatter.
- `score.test.mjs`: Unit tests for scoring functions running under Vitest on canned fixture data (zero network).
- `report.md`: Markdown report table generated by `run.mjs`.

## Running the Unit Tests

The scoring unit tests run offline with Vitest:

```bash
MINDCODE_FAKE_LLM=1 npm test
```

Or run only the eval suite:

```bash
npx vitest run tools/eval/score.test.mjs
```

## Running the Eval Harness

The harness connects to the local Netlify dev server or API server (`--base http://localhost:8888` by default).

### 1. Offline Fake Mode (Free / CI Safe)

Fake mode uses deterministic offline responses without using an OpenRouter API key or spending credits:

1. Start the local server with `MINDCODE_FAKE_LLM=1`:
   ```bash
   MINDCODE_FAKE_LLM=1 npx netlify dev
   ```

2. In another terminal, run the eval harness:
   ```bash
   # Score plans only
   node tools/eval/run.mjs

   # Score plans and builds
   node tools/eval/run.mjs --build
   ```

### 2. Real Mode (Uses OpenRouter API Credits)

> **Warning:** Real mode calls Claude Opus via OpenRouter. Each prompt turn and build incurs OpenRouter API credit costs.

1. Ensure your `.env` contains `OPENROUTER_API_KEY`:
   ```bash
   npx netlify dev
   ```

2. In another terminal, run the eval harness:
   ```bash
   node tools/eval/run.mjs --build
   ```

### CLI Options

```text
Usage: node tools/eval/run.mjs [options]

Options:
  --base <url>       Local API base URL (default: http://localhost:8888)
  --build            Also run build and evaluate generated HTML
  --prompts <path>   Path to prompts JSON file (default: tools/eval/prompts.json)
  --out <path>       Output Markdown report path (default: tools/eval/report.md)
  -h, --help         Show help
```

## Metrics Scored

- **Plan Metrics:**
  - Total node count and source distribution (`user`, `inferred`, `unknown`, `approved`)
  - All 4 taxonomy facets present (`design`, `audience`, `functionality`, `cost`)
  - Number of taxonomy topics matched out of the 18 defined in `ai/taxonomy.ts`
  - Count of child nodes under the "Pages" topic
  - Count of unknown nodes awaiting user decisions
- **Build Metrics:**
  - Byte size of generated HTML
  - Valid closing `</html>` tag present
  - Count of elements with `data-mc` traceability attributes
  - Detection of "Assumed" text in the output
  - Detection of placeholder `href="#"` links
